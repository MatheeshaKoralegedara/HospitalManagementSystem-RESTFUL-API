# Hospital Management Frontend

This folder contains a React + Vite frontend for the Hospital Management REST API.

## Setup

1. Open a terminal in `frontend/`
2. Run `npm install`
3. Run `npm run dev`

The Vite dev server starts on `http://localhost:3000` and proxies `/api` to the backend at `http://localhost:8080`.

## Notes

- The frontend expects the backend to be running on port `8080`.
- The UI includes views for Doctors, Patients, and Appointments.
